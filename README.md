# Tic-tac-toe-AI-Bot
A from-scratch neural network implemented entirely in NumPy and trained to master tic-tac-toe through optimal play. No PyTorch, no TensorFlow—just NumPy, linear algebra, and a terminal interface where you can play against the trained model. 

💾 Dataset available on Kaggle: https://www.kaggle.com/datasets/syedaliakbar110/tic-tac-toe-optimal-moves-minimax-labeled/data
